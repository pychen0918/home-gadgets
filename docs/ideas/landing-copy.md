# 需求測試用介紹文字（6 個用途）

用途：每個用途各做一頁介紹（Google 表單、Notion 公開頁或簡單網頁皆可），
貼到對應的社群，看哪一頁留下聯絡方式的人最多。產品還沒做出來，所以每頁都寫明
「開發中」，只收「開賣時通知我」，不收錢、不寫評價、不寫醫療效果。

每頁共用的結尾（表單欄位）：

1. Email 或 LINE ID（開賣時通知你）
2. 這個問題你現在怎麼解決？（自由填寫）
3. 如果它能解決你的問題，你覺得合理的價格是？
   - NT$500 以下　- NT$500–1,000　- NT$1,000–2,000　- NT$2,000 以上
4. 你比較想要：
   - 買組好的成品　- 買零件自己組（附教學）

## 1. 吃藥確認盒

**標題**：爸媽今天的藥吃了沒？不用打電話問。

藥盒分好了，還是會忘記吃；或是吃過了，卻記不得自己吃了沒。

把現在用的藥盒放進這個盒子。在早上、晚上該吃藥的時段打開過，旁邊的小螢幕就記下
打開的時間。時段快結束還沒打開，盒子會亮燈、發出聲音；再沒打開，就傳 LINE 通知家人。

- 螢幕直接顯示這週每一天、每一餐有沒有打開過，長輩自己看得懂。
- 不需要長輩用手機或 App。
- 網路斷線時，盒子的提醒照樣會響。

注意：它記錄的是「盒子有沒有被打開」，不能確認藥有沒有吞下去。

開發中，留下聯絡方式，開賣時通知你。

**貼文去處**：照顧長輩相關 FB 社團、Dcard 家庭版、PTT（需確認看板規則是否允許）。

**跟現有產品的差別（給你看，不用貼出）**：現有鬧鈴藥盒 300–800 元、Mr.Pill 2,980 元，都不會通知家人。這頁要強調「沒開盒就 LINE 通知家人」。風險：Mr.pill 2018 年募資只達 20%，留名人數少也不意外，要看第 3 題價格。

## 2. 久坐提醒

**標題**：坐下自動開始計時，30 分鐘提醒你起身。

很多人被建議每 30 分鐘起來動一下，但設鬧鐘會忘記開，App 響了也會隨手關掉。

把它放在桌上，你一坐下就自動開始計時，不用按任何按鈕；起身離開兩分鐘就重新計時。
時間快到時燈條變黃，時間到變紅色並發出聲音，直到你站起來。

- 不管你是用電腦還是滑手機，都偵測得到；它偵測的是有沒有人坐在椅子前。
- 不用戴手環，不用裝 App。
- 電子紙螢幕顯示日期和天氣，平常不亮光、不刺眼。

開發中，留下聯絡方式，開賣時通知你。

**貼文去處**：上班族、工程師社群、肩頸痠痛或物理治療相關社團。

**跟現有產品的差別（給你看，不用貼出）**：現有替代品是手環（616–4,690 元）。這頁要強調「不用戴、不用按、坐下自動計時」。

## 3. 出門看板

**標題**：出門前看一眼，就知道要不要帶傘。

放在玄關或門邊的小電子紙看板，每天自動更新：

- 今天的天氣、最高最低溫、降雨機率；會下雨時整塊變紅色。
- 垃圾車今天幾點到（依你家的路線）。
- 停班停課、空氣品質不良時特別標示。

電子紙不發光、很省電，看起來就像一張貼在牆上的紙。資料來自中央氣象署等政府開放資料。

開發中，留下聯絡方式，開賣時通知你。

**貼文去處**：居家布置、智慧家庭（Home Assistant 台灣）社團、新手爸媽社團。

**跟現有產品的差別（給你看，不用貼出）**：Kokonna、TRMNL 都沒有台灣資料。這頁要強調降雨、垃圾車、停班停課這些在地資訊。

## 4. 會議室門牌

**標題**：門口就看得到會議室現在有沒有人用、下一場幾點。

小公司的會議室常常被搶：走過去才發現有人在用，或是有人預約了卻沒來。

貼在會議室門口的電子紙門牌，跟你們的 Google 行事曆同步，顯示：

- 現在：使用中或空閒，這場開到幾點。
- 接下來：今天後面還有哪幾場。

目標是用電池運作、不用拉電線：電子紙只在換內容時用電。

開發中，留下聯絡方式，開賣時通知你。

**貼文去處**：新創、行政總務、共同工作空間相關社團；LinkedIn。

**跟現有產品的差別（給你看，不用貼出）**：台灣只有 6,600–9,400 元的插電安卓平板門牌。這頁要強調「用電池、不拉線、同步 Google 行事曆」，可以在第 3 題加一個「NT$2,000–3,000」選項。

## 5. 店門口公告牌

**標題**：今天臨時公休，用手機改一下，門口的牌子就換了。

小店的營業時間、公休、今日售完、臨時通知，常常要跑到門口改白板，或是客人到了才知道。

一塊放在門口或櫃台的電子紙公告牌，用手機輸入文字，幾秒內更新：

- 營業中、休息中，可以照營業時間自動切換。
- 臨時公告：今日公休、售完、晚點開門。
- 白天陽光下也看得清楚，不像螢幕會反光。

開發中，留下聯絡方式，開賣時通知你。

**貼文去處**：小店老闆、餐飲業、手作市集相關社團。

**跟現有產品的差別（給你看，不用貼出）**：商用電子紙看板要 2 萬元以上，價籤要基地台。這頁要強調「手機或 LINE 改內容、幾千元以內」。

## 6. 寵物照護提醒

**標題**：狗狗的心絲蟲藥、驅蟲、疫苗，下一次是哪天？

寵物的藥和疫苗是每個月、每年一次，日子一久就忘了上次是什麼時候。

一塊放在家裡的小電子紙，顯示下一件要做的事和剩幾天：

- 例如「11/15 心絲蟲藥（還有 5 天）」，當天變紅色。
- 做完按一下按鈕，自動排好下一次的日期。
- 也可以傳 LINE 提醒家裡其他人。

開發中，留下聯絡方式，開賣時通知你。

**貼文去處**：狗狗、貓咪飼主社團。

**跟現有產品的差別（給你看，不用貼出）**：台灣沒有任何實體寵物提醒裝置，只有 App。可以加一句「狗每年必須打狂犬病疫苗，忘了打最高罰 15 萬」。

## 怎麼判斷結果

- 每一頁用同一個表單格式，貼文內容長度相近，貼文時間相近。
- 兩週後比較：每頁的瀏覽人數（Google 表單看不到瀏覽數，可改用短網址服務計算點擊數）、
  留聯絡方式的人數、第 3 題的價格分布、第 4 題成品還是 DIY。
- 留聯絡方式的比例最高、而且大多選「NT$1,000 以上」的那一頁，最值得先做。
- 第 2 題「現在怎麼解決」的回答，會告訴你真正的競爭對手是誰。
